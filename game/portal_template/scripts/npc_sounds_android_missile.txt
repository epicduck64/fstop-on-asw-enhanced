// flyby, the impacts and the burst were all silent. Mapped onto content that is mounted:
// Portal 1's rocket (weapons/rocket/*, the sounds its rocket turret plays) for the flyby and
// the fuse, a hard-surface impact for the world hit, the sound the leak's own android script
// already uses for body hits, and - for the burst - the wave behind the engine's
// BaseExplosionEffect.Sound, so this missile booms like every other explosion in the game.
